# 🔢 Operações com Matrizes em Python

Programa desenvolvido em Python para trabalhar com matrizes e realizar cálculos a partir dos valores informados pelo usuário.

## Funcionalidades

- Preenchimento de uma matriz
- Organização dos valores em linhas e colunas
- Cálculo de informações a partir dos elementos da matriz
- Exibição dos resultados no terminal

## Tecnologias

- Python 3

## Conceitos praticados

- Listas bidimensionais
- Matrizes
- Laços de repetição aninhados
- Operações matemáticas
- Acesso e manipulação de elementos

## Como executar

```bash
python matrix-operations.py
```

## Objetivo

Praticar estruturas de dados bidimensionais e compreender como organizar e processar informações em matrizes.
